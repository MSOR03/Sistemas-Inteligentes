## 1.Picas&Fijas

## 2.Diamond rush agent
This project use typical AI algorithms like:
- A* and average A* 
- BFS(Breadth First Search) 
- Heuristics

Using the algorithms that have been mentionated the agent makes a screenshot and use BFS 
to find the neighbors nodes,obviously use A* to trace a route, if the cost is high it will
use average A* and heuristics to find the minor distance and take a path.

## Technologies
